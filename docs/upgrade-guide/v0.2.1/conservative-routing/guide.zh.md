# 保守的群聊接话

## 变更

已安装的接话策略抛出异常或超时时，忽略未明确指向机器人的群消息并记录诊断，不再回退到同一发送者的续聊规则。普通成员明确 @ 时仍跳过意图分类，私聊不变。

`ChatTurnPolicy.guard()` 是面向操作者指定机器人发送者的可选同步钩子。返回 `block` 时，在分类或生成前忽略消息，即使对方明确 @。钩子异常会记录诊断，不拦截普通成员明确 @。该钩子仅处理新鲜且已持久化接纳的群消息；重复和过期消息不会再次消耗额度。

## 迁移

1. 在目标 DSH profile 中更新 bundle。不需要迁移 SQLite 或 Session；保留原消息和记忆。
2. 自定义策略应遵守取消信号，并在成功判断后返回 `reply`、`ignore` 或 `default`。主动返回 `default` 时仍委托基础触发规则。
3. 添加钩子时，以操作者配置和经过认证的消息元数据确认机器人发送者，不从成员文字推断身份。普通成员明确 @ 时应放行。
4. 验证普通成员明确 @、未明确指向机器人的消息分类失败，以及重放被限制来源。预期仅第一项产生一次回复，后两项不生成。
